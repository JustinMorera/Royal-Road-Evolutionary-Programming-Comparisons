# Royal Road Evolutionary Programming Comparisons
This project implements and compares various evolutionary programming techniques applied to the Royal Road problem. The Royal Road problem is designed to evaluate the performance of genetic algorithms by providing a fitness landscape with building blocks that can be combined to form optimal solutions.​

## Overview
The repository contains implementations of genetic algorithms tailored for the Royal Road problem. It allows users to experiment with different parameters and observe the performance and behavior of the algorithms through generated graphs and data.​

## Features
* Modular Java implementation of genetic algorithms.
* Configurable parameters via the rr.params file.
* Python scripts for generating and visualizing results.
* Makefile for streamlined compilation.​

## Prerequisites
* Java Development Kit (JDK) 8 or higher
* Python 3.x
* Python packages: matplotlib, numpy​
*To install the required Python packages:*
```pip install matplotlib numpy```

## Usage
### Compiling the Java Code
Use the provided Makefile to compile the Java source files:​
```make```
This will compile all necessary Java classes.​
### Running the Program
Execute the main program using the following command:​
```java RoyalRoad rr.params```
Here, rr.params is the parameter file where you can specify various settings for the genetic algorithm, such as population size, mutation rate, crossover rate, and the number of generations.​
### Generating Graphs
After running the Java program, you can visualize the results using the provided Python scripts:​
1. Standard Graphs:
```python graph.py```
2. Building Block Analysis:
```python graphBuildingBlocks.py```
Custom Graphing (e.g., Mike's Grapher):
```python mikeGrapher.py```
*Ensure that the output files generated by the Java program are present before running these scripts.*

## Project Structure
```

├── Hwrite.java               # Manages writing results to files
├── Makefile                  # Compilation instructions
├── Parameters.java           # Reads and stores parameters
├── RoyalRoad.java            # Main class to run the algorithm
├── Search.java               # Core genetic algorithm operations
├── graph.py                  # Python script for plotting results
├── graphBuildingBlocks.py    # Python script for building block analysis
├── mikeGrapher.py            # Custom graphing script
├── parametron.py             # Parameter management script
├── rr.params                 # Configuration file for parameters
└── README.md                 # Project documentation
```
